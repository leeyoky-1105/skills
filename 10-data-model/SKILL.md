## 核心理念

> **10 只做一件事：定义模块的数据实体、字段约束、存储引擎以及 Storage 类方法清单。"怎么调接口"在 09；"数据怎么存"在本文。**
>
> AI 负责引导提问和结构化整理，人负责提供真实的数据模型设计。

## 关键行为准则

### AI 可以做

| ✅ 可以做 | 说明 |
|:---|:---|
| 生成实体框架 | 供用户填写 |
| 建议方法命名 | 供用户确认 |
| 对齐 09 API | 建立映射关系 |
| 生成文档结构 | 按模板组织 |

### AI 绝不可以做

| 🛑 绝不可以 | 原因 |
|:---|:---|
| 臆造实体关系 | 需后端确认 |
| 臆造字段名和类型 | 需与代码一致 |
| 自行定义业务逻辑 | 需业务方确认 |
| 臆造 Storage 方法 | 需与架构一致 |
